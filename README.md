# Sales Data Analysis

## Overview

A Data analytics project using Python and Pandas to analyze sales data and identify revenue trends, product performance and regional patterns.

## Objectives

- Clean and inspect sales data
- Calculate revenue
- Analyze product performance
- Analyze regional sales
- Identify monthly revenue trends
- Generate basic business insights

## Technologies

- Python
- Pandas
- Matplotlib
- CSV

## Analysis Performed

- Missing-value analysis
- Revenue calculation
- Product-level analysis
- Regional analysis
- Monthly sales analysis
- Data visualization

## Key Insights

The analysis compares product revenue, sales volume and regional performance to identify patterns that can support business decision-making.

## How to Run

```bash
pip install -r requirements.txt
python sales_analysis.py
